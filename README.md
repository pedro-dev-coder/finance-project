# Finance Project (React + .NET Core)

Projeto baseado no curso de finanças utilizando React no frontend e .NET Core no backend, integrado com a API Twelve Data.

## Tecnologias
- Backend: .NET 8 (Minimal API)
- Frontend: React + Vite
- API externa: Twelve Data

## Como rodar

### Backend
```
cd backend/Finance.Api
dotnet run
```

Defina sua API KEY:
```
setx TWELVE_DATA_API_KEY SUA_CHAVE
```

### Frontend
```
cd frontend
npm install
npm run dev
```

## Funcionalidades
- Buscar cotação de ações
- Histórico de preços
- Visualização em gráfico
